## FastAPI standards (apply unless the project says otherwise)

- `Annotated[...]` for `Query`/`Path`/`Body`/`File`/`Depends`; `status.HTTP_*` constants; an explicit `response_model` on every endpoint.
- Keep routes thin: validate and delegate; no business logic or SQL in route functions.
- Never call blocking code inside `async def`; offload with `anyio.to_thread.run_sync` or use async drivers/clients.
- Separate liveness (no dependencies) from readiness (checks the database); never leak internals in error bodies.
- Resources with a lifecycle (DB pool, HTTP clients) start and stop in the root app's lifespan; Starlette does not run the lifespan of mounted sub-apps.
- Dependency overrides are per app: in tests apply them to the sub-app that owns the dependency.
- Enable Ruff's `ASYNC`, `S` and `B` rule sets when the project has no equivalent.
